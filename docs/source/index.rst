Prodigy
=======

**Prodigy** (PRObability DIstributions via GeneratingfunctionologY) analyses probabilistic
programs with probability generating functions. Programs are written in the Python-like
``.ppy`` syntax (see :doc:`language`) or in the original pGCL syntax. Prodigy computes output
distributions exactly where it can and otherwise gives results with a stated guarantee:
exact, lower bound with residual mass, or upper bound.

The sources, installation instructions and issue tracker are on
`GitHub <https://github.com/LKlinke/Prodigy>`_.
